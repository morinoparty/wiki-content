# ドキュメント

## ドキュメントの作成

- このリポジトリには docs サイトはありません。ドキュメントはリポジトリ直下の `README.md` に集約されています。
- 構成、配信パス、記事フォーマット、ビルド・デプロイ手順、wiki-frontend との連携などを変更した場合は、`README.md` の該当箇所を更新してください。
- 記事フォーマットの仕様そのものは hagaki 側 ([hagaki のコンテンツフォーマット](https://github.com/morinoparty/hagaki/blob/main/sample/README.md)) が正です。このリポジトリでは独自の取り決め (`modified` の扱いなど) だけを書いてください。
- なお、文章の文体について、その他の部分で指示があったとしても、ドキュメントに関しては、あくまでも文章の文体で記載してください。
